## 3. P, H, E 계산식 (MVP 간단 버전, 숫자는 초기값)

| 항목 | 식 | 비고 |
|---|---|---|
| **P** 빈집 가능성 | r_i = 기준연도 분포에서 지표 i의 백분위(0~1, 위험 방향으로 맞춤)<br>P_raw = 사용 가능한 r_i의 평균 (동일가중)<br>P = P_raw의 기준연도 백분위 | 확률이 아니라 순위 점수. 범주형 ⑤는 규칙값(0/1)을 그대로 평균에 넣음. 결측 지표는 평균에서 빼고 사용 지표 수 기록 |
| P 하한 | P' = max(P, 0.05) | 0점으로 영원히 안 뽑히는 건물 방지 |
| **H** 위해 단계 | H = 단계 계수 × 상태 계수<br>단계: 제11조 1호 1.0 / 2호 0.7 / 3·4호 0.5 / 신고 없음 0.4<br>상태: 공람안 3등급 1.0 / 2등급 0.8 / 1등급·미등록 0.6 | 1호(붕괴·화재·범죄) > 2호(위생) > 3·4호(경관·생활환경). 3등급=철거 대상 |
| **E** 노출 | E = 0.5 + 0.5 × 백분위(반경 100m 주택 동수) | 0.5가 하한. 주변에 사람이 많을수록 위해가 퍼짐 |
| **기한** | 신고 접수 후 남은 일수 ≤ 7일이면 1차 정렬키로 맨 앞 | 시행령 제10조의3 "30일 이내 현장조사" |
| **불확실성 가점** | U = 0.1 × min(마지막 확인 후 경과일 / 365, 1) | 오래 확인 안 한 곳을 조금 끌어올림 |
| **최종** | S = P'·H·E + U<br>점검 목록 N건 = 기한 임박 건 → 나머지는 0.9N을 S 순, 0.1N을 상위 밖에서 무작위 | N은 점검 용량(초기값 주 20건). 무작위 10%는 편향 방지·새 정답 데이터 확보용 |
| 로지스틱(보조) | 158호 = 1, 나머지 주택 = 0, 검증용 지표로 적합 | 계수 **부호만** 확인(가중치로 쓰지 않음) |

## 4. 검증 방법과 MVP에서 보여 줄 숫자

| 방법 | 내용 | 보여 줄 숫자 |
|---|---|---|
| V1 recall@k, 리프트 | 검증용 지수(②는 자기 지번 제외, 보조 지표·⑤ 제외)로 주택 순위. 158호가 상위 k%에 든 비율. 지번 가림 때문에 후보 건물 중 **최고 순위(낙관)·평균 순위(보수)** 두 가지로 보고 | recall@10%, recall@20%, 리프트@10%(= recall/0.1). 비교 기준: 무작위, 연식 단일 지표. 동 내부 순위 결과도 함께(동 효과만 재는지 확인) |
| V2 거주확인 9호 | 공람안에서 조사 후 거주가 확인돼 빠진 9호(음성 사례). 158호와 같은 방식으로 위치 근사 필요 | 9호 P 백분위 중앙값 vs 158호 중앙값, 9호 중 상위 N에 든 수. n=9라 검정이 아니라 사례 제시 |
| V3 민감도 | 지표 하나씩 빼기, 가중치 ±50% 무작위 1,000회, 백분위 vs Jenks, 최근접 거리 vs 300m 개수 | 상위 N 유지율 범위, 순위 Spearman 상관, recall@10% 범위, 로지스틱 계수 부호 표 |

> AUC는 쓰지 않는다(음성 9건). "빈집이 아닌 집을 얼마나 걸러내는가"(상위 10%만 보면 몇 % 찾는가)로 말한다.

## 5. 데이터 품질 문제와 MVP 처리

| 문제 | 규모 | MVP 처리 |
|---|---|---|
| 용도 빈칸 | 건물 72,171동 중 약 48% | 기본: 주택 23,723동만 대상. 158호 후보 건물이 빈칸 건물에 걸리는 수를 따로 집계해 누락 규모 보고. 대부권역 단독주택 누락 주의. 보충안은 6장 결정 |
| 사용승인일 결측 | 전체 38%(주택은 21동) | 주택 기준이면 영향 작음. 결측 플래그만 |
| 지번 가림 위치 오차 | 근사 오차 중앙값 39m, 90% 128m, 최대 564m | 오차 열 유지. 거리 50m 미만은 같은 값으로 묶음(오차보다 정밀한 구분 금지). 검증은 후보 건물 집합 단위. 오차 300m 초과 빈집 제외 실험을 민감도에 포함 |
| 좌표 | 건물 외곽 사각형 중심점, 큰 건물 수십 m 오차 | MVP 허용. 문서에 한계로 명시 |
| 법정동·행정동 불일치 | 건물·빈집은 법정동, 인구는 행정동 | 행정동 경계 SHP로 건물 좌표 공간조인(1순위). 없으면 매핑표, 다대다는 대표 행정동 1개 |
| 지오코더 이용조건 | 변환 결과 별도 DB 저장 금지 | 시연용으로만 사용. 운영은 시 내부 좌표·정보공개청구 정확 지번 |
| 공개 범위 | 제15조⑥ 개별 빈집 공개 제한 | 공개 화면은 집계 단위만 |

## 6. 팀이 결정해야 할 것

| # | 결정 | 선택지 | 권장(초안) |

| 1 | 정규화 방식 | 백분위(기준연도 고정) / Jenks 5등급 | 백분위. Jenks는 민감도 비교용 |
| 2 | 용도 빈칸 처리 | 제외 / 층수·구조·연면적 규칙으로 주택 추정 / 건축HUB API로 주용도 보충 | MVP는 제외 + 누락 규모 보고, API 승인되면 보충 |
