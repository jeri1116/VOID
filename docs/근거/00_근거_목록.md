# 00. 근거 목록 (Codex용 색인)

PPT·기획안·제안서를 쓸 때 **이 파일 하나로 근거를 찾는다.** 숫자는 아래 표에서만 가져온다.

- 작성일: 2026-11-08
- 경로 표기: `docs/근거/` 기준 상대경로. 예) `01_공식원문/핵심정리.md`
- 확인 수준
  - **[확인]**: 원문(PDF·회의록·기사 본문·통계표)을 직접 열어 확인
  - **[검색요약]**: 검색 요약·2차 자료만 확인. 발표 전 원문 확인 권장
  - **[자체계산]**: 팀 데이터로 직접 계산(공식 통계 아님)
- 원문 PDF 위치
  - 공람안: `data/안산시 빈집정비계획(안) 주민공람용.pdf` (29쪽, 쪽은 하단 인쇄 쪽)
  - 범정부 종합계획: `data/(관계 부처 합동) 범정부 빈집 관리 종합계획 발표, 보도자료(5.1. 08시).pdf`
  - 공람안 158호 목록: `data/안산 빈집정비계획 공람안 빈집목록.csv`
- 옛 방향 자료(`이전문서/`)는 근거로 쓰지 않는다. 이 폴더 안에서도 `〔최종안과 다름: …〕` 표시가 붙은 문장은 근거로 쓰지 않는다. `〔갱신: …〕`은 나중에 확인된 내용이다.

## 0. 최종 방향 (판단 기준)

| 항목 | 최종안 |
|---|---|
| 서비스 | 안산시 빈집정비계획(2026~2030, 주민공람안)이 정한 **등록 빈집 정기 점검**(상시관리 123 + 안전조치 21 = 144호, 6개월~1년, 사진·일지)을 실제로 돌리는 도구 |
| 지도 | **SOS 긴급도** = 빈집 긴급도. "어디부터 가야 하나"를 보여 준다. 주변 위험 지수가 아니다 |
| 색 | 진한 빨강(1단계 위해) / 빨강(2단계 또는 시 안전조치·철거 대상, 조치 전) / 주황(3단계 또는 점검 기한 지남) / 초록(이상 없음·조치 완료) |
| 보라 | **시민 제보 구역**(250m 격자, 30일 안 현장조사) |
| 규칙 | 가중치·점수 없음. 위해 판정과 기한 중 더 나쁜 쪽. 주기는 6/12개월. 피해 범위 3조건(생활시설 100m, 주변 빈집, 주택 밀집)은 주기와 동점 순서에만 쓴다 |
| 화면 | 시민 제보(`/report`), 시 담당자 지도·상세 패널(`/admin`). 순찰대는 스크린샷만 |
| AI | 현장 사진 판독 → 5개 항목·단계 후보·일지 초안. 확정은 담당자 |
| 데이터 | 공람안 158호(방문지 130곳). 시작 상태 빨강 24 / 주황 65 / 초록 41(단위: 곳) |
