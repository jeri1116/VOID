# 시연 시나리오 (발표 7장, 95초)

> 기준: 지금 앱(`app/`, 브랜치 `feature/real-data`)에서 실제로 동작하는 기능만 쓴다.
> 발표 흐름과 멘트 원칙은 [발표 기획안 7장](../이전문서/2026-11-08_발표준비/발표_기획안_7분.md)을 따른다. 그 문서의 "노란 구역"은 **보라 구역**으로 바뀌었다.

## 1. 심사위원이 가져가야 할 것

| # | 보여줄 핵심 | 화면에서 보이는 증거 |
|---|---|---|
| 1 | **어디부터 가야 하는지 보인다** | 실제 공람안 130곳의 4색 지도, 색마다 "왜 이 색인지" 이유 |
| 2 | **시민 제보가 담당자 업무로 이어진다** | 보라 제보 구역, 30일 현장조사 기한(D-30) |
| 3 | **AI는 초안, 판단은 사람** | AI 5개 항목 관찰·"확인 불가"·일지 초안 → 담당자가 단계 확정 |
| 4 | **확정과 조치가 바로 지도에 반영된다** | 주황 → 진한 빨강 → 초록, KPI 숫자 변화, 다음 점검일 |
| 5 | **한 빈집의 기록이 남는다** | 타임라인: 실태조사 → 제보 연결 → 점검 → 조치 완료 |

## 2. 시연 대상

**빈집: 일동 541-\*\***
- 주황 · 점검 기한 130일 지남(주기 6개월) · 다세대 1호 · 시 등급 1 · 상시관리
- 피해 범위 3/3: 100m 안 학교·어린이집·경로당, 같은 구역에 다른 빈집 2곳(일동 536·542), 주변 주택 밀집
- **고른 이유**
  - 주황에서 시작해야 한다(명세 3.3).
  - 피해 범위 3개가 모두 켜져 있어 "왜 먼저 가야 하는지" 설명이 쉽다.
  - 와동·부곡동·선부동·일동은 발표 2장의 상위 4개 동이다.
  - 시연용 제보가 미리 붙어 있지 않아서, 연결하면 D-30 배지가 새로 생기는 게 잘 보인다.
  - 집이 250m 구역 경계에서 80m 이상 안쪽에 있다. 시민 화면에서 집 근처를 누르면 같은 구역에 잡힌다.

**예비: 와동 801-1\*\*** (주황, 피해 범위 2/3, 구역 안에 빈집 1곳뿐, 경계에서 117m)

**시민 제보 내용**(미리 작성)
- 카테고리: 무단 침입
- 제목: 현관문이 며칠째 열려 있어요
- 내용: 밤에 사람이 드나드는 소리가 납니다
- 사진 1장(선택)

**사진**(AI 담당이 준비. 공공도로에서 찍은 외관이거나 사용 권한이 있는 사진. 얼굴·차량번호·주소 없게)
- 현장 사진: 출입문 개방·파손이 보이는 빈집 외관. AI가 보안 "발견" → 1단계 후보를 내야 한다.
- 조치 완료 사진: 출입구를 막은 모습. **앱에 아직 이 사진을 받는 칸이 없다(7장 참고).**

## 3. 시연 직전 준비 (리허설 포함 15분)

1. **리허설:** 아래 4장 흐름을 처음부터 끝까지 한 번 돈다.
   - 현장 사진이 **LIVE**로 판독되는지 본다.
   - 성공하면 `app/fixtures/ai-cache.local.json`에 자동 저장된다. 인터넷이 끊겨도 같은 사진이면 같은 결과가 나온다.
2. **리셋:** 터미널에서 Ctrl+C로 끄고 `npm.cmd run dev`로 다시 켠다. 처음 상태(빨강 24 · 주황 65 · 초록 41, 제보 5건)로 돌아간다.
3. **탭 1 `/admin`:** 전체 지도가 보이는 기본 화면. KPI가 처음 숫자인지 확인한다.
4. **탭 2 `/report`:** 제보를 **제출 직전까지** 미리 채워 둔다.
   - 카테고리·제목·내용·사진 → "다음: 위치 선택"
   - 위치: 지도를 일동 쪽으로 확대해 **일동 541 근처**를 누른다. "일동 일대 · 250m 구역"이 뜨면 된다.
   - 위치 찾는 법: 리허설 때 `/admin`에서 "일동 541"을 검색해 주변 길·건물 모양을 기억해 둔다. 집에서 80m 안이면 같은 구역이다.
   - **제보 제출 버튼은 누르지 않고 둔다.**
5. **브라우저:** 확대 100%, 알림 끄기. 탭 1과 탭 2만 남긴다.
6. **녹화 백업:** 리허설 화면을 녹화해 둔다. 지도 배경은 인터넷이 있어야 나온다.

## 4. 시연 흐름 (95초)

조작 1명(FE), 멘트 1명(발표자). 조작자는 멘트가 끝나기 전에 다음 버튼 위에 마우스를 올려 둔다.

| 시간 | 화면 · 조작 | 보여줄 변화 | 멘트 |
|---|---|---|---|
| 0–15초 | **탭 1** 전체 지도 → 검색창에 "일동 541" → 목록에서 선택 | 4색 지도, KPI. 패널: 주황, "점검 기한 130일 지남", 피해 범위 3/3 | "실제 공람안 158호를 130곳으로 묶은 지도입니다. 이 빈집은 점검 기한이 130일 지났고, 학교 가까이 빈집이 모인 곳이라 먼저 가야 합니다. 위치는 근사값이고 점검 이력은 시연용입니다." |
| 15–25초 | **탭 2** "제보 제출" | 접수번호, "일동 일대" 구역 | "시민은 정확한 집이 아니라 250m 구역으로 제보합니다. 빈집 위치는 시민에게 보이지 않습니다." |
| 25–35초 | **탭 1**로 돌아옴 → 패널의 "이 빈집에 연결" | 보라 구역이 생김, 신규 제보 5→6, **점 색은 주황 그대로**. 연결하면 점에 **D-30** 배지 | "제보만으로 색은 바뀌지 않습니다. 담당자가 구역 안 등록 빈집을 확인하고 연결하면, 법정 현장조사 기한 30일이 붙습니다." |
| 35–60초 | 현장 사진 선택 → "업로드 후 AI 판독 요청" → 일지 한 단어 고치기 | **LIVE** 배지, 5개 항목(발견·이상 없음·**확인 불가**), 단계 후보 1단계, 일지 초안 | "AI는 사진에 보이는 사실만 정리하고, 안 보이는 건 확인 불가로 둡니다. 일지 초안은 담당자가 고칩니다." |
| 60–70초 | "위해 단계 확정" | **진한 빨강**, KPI 진한 빨강 0→1·주황 65→64, D-30 배지 사라짐(현장조사 완료) | "출입 통제가 필요하다는 판단은 담당자가 확정합니다. 확정하는 순간 지도와 현황판이 함께 바뀝니다." |
| 70–85초 | "조치 완료" | **초록**, 다음 점검 2027-05-08, KPI 진한 빨강 1→0·초록 41→42 | "봉쇄를 마친 뒤에도 6개월 뒤 점검이 다시 잡혀 관리가 이어집니다. 시연이라 날짜는 같은 날로 기록됩니다." |
| 85–95초 | 패널 "기록"으로 스크롤 | 실태조사 → 제보 연결 → 점검 → 조치 완료 | "이 빈집에 무엇이 있었고 어떻게 대응했는지 한 기록에 남습니다." |
| (여유 시) | Esc → "시민 제보 30일" 탭 | 제보가 "연결: 일동 541", "현장조사 완료"로 표시 | "제보한 시민의 건도 처리 상태가 남습니다." |

KPI 숫자는 지금 현황판(진한 빨강과 빨강을 따로 세는 6칸 안) 기준이다. "긴급(빨강 이상)" 한 칸으로 쓰는 경우에는 24 → 25 → 24로 읽는다.

## 5. 문제가 생기면

| 상황 | 대응 |
|---|---|
| AI 결과에 **캐시** 배지가 뜸 | "인터넷 문제로 저장된 분석 결과를 보여 드립니다"라고 말하고 계속한다. LIVE라고 말하지 않는다. |
| AI가 오래 걸림 | 멘트로 시간을 채운다. 지금 최대 대기는 약 40초다(7장 2번). |
| 보라 구역·패널 제보가 안 뜸 | 5초 기다리거나 탭을 한 번 바꿨다 온다(5초마다 자동 갱신). |
| 패널에 "이 구역에 들어온 연결 전 제보"가 끝내 안 뜸 | 위치를 다른 구역에 찍은 것이다. 녹화본으로 넘어간다. 리허설 때 반드시 확인한다. |
| 지도 배경이 안 나옴 | 인터넷 문제. 녹화본으로 넘어간다. |
| 잘못 눌러 상태가 꼬임 | 녹화본으로 넘어간다. 시간이 있으면 서버 재시작(약 10초)으로 처음 상태로 돌린다. |

## 6. 시연에서 하지 않을 말

- "범죄를 줄입니다", "실제 방치 현황입니다". 초기 색은 가정한 점검일(2026-01-01) 기준이다.
- "클릭하면 조치가 끝납니다". 조치 완료는 현장 조치 뒤 기록하는 장면이다.
- "144호"와 "130곳"을 같은 단위로 쓰지 않는다. 지도는 158호를 묶은 130곳이다.
- 정확한 주소. 화면의 지번은 가린 지번이다.

## 7. 시연 전에 끝내야 할 개발

1. **조치 완료 사진 받기**
   - 지금은 "조치 완료 (봉쇄 완료 사진 등록)" 버튼만 있고 사진을 받지 않는다.
   - 서버는 사진을 받게 돼 있어서 패널에 사진 고르기만 붙이면 된다.
2. **AI 대기 시간 줄이기**
   - 지금은 Gemini 20초, GPT 20초를 기다린 뒤 캐시로 넘어간다. 최악이면 약 40초다.
   - 시연용으로 각 8초 정도로 줄이는 것을 권장한다.
