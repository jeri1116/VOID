# VOID: 안산 빈집 SOS 긴급도 관리

- 안산시 빈집정비계획(2026~2030)의 등록 빈집 중 **어디부터 가야 하는지** SOS 긴급도 지도로 보여 준다.
- 시민 제보 → 현장 사진 AI 판독 → 담당자 확정 → 조치 완료를 한 기록에 남긴다.
- 안산시 지역문제 해결 AI 해커톤 출품작이다.

## 읽는 순서

| 용도 | 순서 |
|---|---|
| PPT·기획안·제안서 | [docs/기획_최종안.md](docs/기획_최종안.md) → [docs/근거/00_근거_목록.md](docs/근거/00_근거_목록.md) → 필요하면 `docs/근거/0X_...` 원자료 |
| 개발 | [docs/개발명세.md](docs/개발명세.md) → [docs/와이어프레임.html](docs/와이어프레임.html) → `app/` |

## Codex·AI 도구에게 주는 지시

> **1. `이전문서/` 폴더는 읽지 않는다.** 옛 방향이 섞여 있다(순찰대 점검, 야간 운영, 빈집 예측, 점수 0~100, Jenks, SOS = 주변 위험 등).
>
> **2. 숫자는 `docs/근거/00_근거_목록.md`에 있는 것만 쓴다. 출처를 붙인다.**
>
> **3. SOS는 빈집 긴급도다.** 색은 4단계(진한 빨강 / 빨강 / 주황 / 초록)다. 노랑 = 시민 제보 구역이다. **점수·가중치를 만들지 않는다.**
>
> **4. "범죄 감소"를 약속하지 않는다.**
>
> **5. 해커톤 제외 분야(교통·청년·다문화)는 주제로 삼지 않는다.**

| 경로 | 내용 |
|---|---|
| `docs/기획_최종안.md` | PPT·제안서의 기준 문서(작성 중) |
| `docs/개발명세.md` | 개발 기준(완성). 시연 시나리오, SOS 색 규칙, 데이터, API, 역할, 일정 |
| `docs/와이어프레임.html` | 확정 화면. 브라우저로 연다 |
| `docs/근거/00_근거_목록.md` | 주장별 근거·수치·출처 색인(작성 중) |
| `docs/근거/01_공식원문/` | 공람안 핵심정리, 빈집법 핵심조항 |
| `docs/근거/02_실행공백_근거/` | 안산시는 정기 점검을 정했지만 실행 수단이 비어 있다는 근거 |
| `docs/근거/03_반론대응_근거/` | 인구 유출, 주거 노후화, 빈집 밀집, 빈집과 범죄 연관 |
| `docs/근거/04_차별성_사례/` | 현장점검 도구, 전국 AI 빈집지수, 종로구 사례 |
| `data/` | `houses.json`(앱 입력), 원천 CSV·PDF |
| `scripts/` | `build_houses.py`(houses.json 생성) 등 |
| `app/` | Next.js 앱. 별도 git 저장소([github.com/yejin1228/wnpwnpdldi](https://github.com/yejin1228/wnpwnpdldi)). VOID git에서는 제외 |
| `이전문서/` | 옛 보고서(reports 01~29), 옛 조사 노트, 가상 데이터. 옛 방향이 섞여 있다. 읽지 않는다 |

## 데이터 메모

| 항목 | 내용 |
|---|---|
| 파일 | `data/houses.json` |
| 원천 | 실제 공람안 빈집 158호를 방문지 130곳으로 묶음 |
| 위치 | 근사값(오차 중앙값 39m) |
| 시작 상태 | 빨강 24 / 주황 65 / 초록 41 |
| 가정 | 기준일 2026-11-08, 마지막 점검일 2026-01-01 |
| 다시 만들기 | `python -I -X utf8 scripts/build_houses.py` |
| 필요 파일 | `data/안산 건물 전체 (GIS건물통합정보 202610).csv`. 대용량이라 git에 없다. 따로 받는다 |

## 앱 실행

```bash
cd app
npm install
npm run dev
```

- Gemini 키는 `app/.env.local`의 `GEMINI_API_KEY`에 둔다.
- 이 키는 서버에서만 쓴다.

## 지킬 것

- 시민 화면에 개별 빈집 위치를 띄우지 않는다(빈집법 제15조⑥).
- API 키를 노출하지 않는다. 클라이언트 코드와 git에 넣지 않는다.
