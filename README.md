# VOID: 안산 빈집 안전 관리 (안산시 지역문제 해결 AI 해커톤)

**한 줄:** 안산시 빈집정비계획(2026~2030)이 정한 빈집 144호 정기 점검을 실제로 돌리는 도구. 어느 빈집을 먼저 가야 하는지 지도(SOS 긴급도)로 보여 주고, 사진 한 장으로 점검 기록을 남긴다.

> **먼저 읽을 것:** `reports/27`(그라데이션 규칙, 확정) → `reports/25`(솔루션 계획) → `reports/24`·`26`(근거)

---

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `reports/` | 팀이 읽는 정리 문서. 시간순 번호이고 이름은 `번호 [태그] 제목` 형식이다. 아래 표 참고 |
| `research_notes/` | reports를 쓸 때 근거로 삼은 조사 원자료. 출처 URL과 태그([확인]/[검색요약]/[추정])가 붙어 있다 |
| `data/` | 분석에 쓴 데이터(CSV) |
| `scripts/` | 데이터 추출·계산용 파이썬 스크립트 |

### reports/ 태그

| 태그 | 뜻 |
|---|---|
| [조사] | 사실 조사 |
| [아이디어] | 아이디어 탐색(초기) |
| [근거] | 발표에 쓸 근거 모음 |
| [지표] | SOS 지표 설계(초기, 빈집 예측용) |
| [설계] | 서비스·MVP 설계 |
| [발표] | 발표·질의응답 준비 |

**지금 방향과 맞는 문서는 24~28번이다.** 1~23번은 이전 방향이다. 순찰대 점검, 야간 축, 빈집 예측용 SOS 같은 내용이 섞여 있으니 참고용으로만 본다.

| 번호 | 문서 | 상태 |
|---|---|---|
| 28 | MVP 기획(방향 점검용) | 현재. 22번 대체 |
| 27 | SOS 긴급도 그라데이션 규칙 | **확정** |
| 26 | "빈집 수가 적다"는 반론 대응 근거(인구 유출·노후화·밀집) | 현재 |
| 25 | 빈집 상시관리 솔루션 계획 | 현재. 3장 우선순위는 27번으로 대체됨 |
| 24 | 상시관리 솔루션 근거(실행 공백) | 현재 |
| 23 | 심사위원 예상 지적점과 보강 계획 | 참고(일부 옛 방향 기준) |
| 1~22 | 주제 탐색, 초기 설계, SOS 지표 | 이전 방향 |

## 지켜야 할 것

- **개별 빈집 주소를 공개 화면에 띄우지 않는다.** 빈집법 제15조⑥ 때문이다.
- **해커톤 제외 분야는 주제로 삼지 않는다.** 교통·청년·다문화가 여기에 해당한다.
- **발표 문장은 24~28번에서 가져온다.** 1~23번 문장에는 옛 방향 표현이 남아 있다.
