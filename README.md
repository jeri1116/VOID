## 무엇을 만들었나

**문제:** 안산시 계획(안)은 계획 대상 158호 중 144호(상시관리 123 + 안전조치 21)를 6개월~1년마다 점검하고 사진·일지로 남기라고 정했다. 그런데 공람본에는 **어떤 순서로, 무엇으로 기록할지**가 없다. 인구는 2011년 정점보다 15.1% 줄었고, 30년 넘은 주택은 37%(2026) → 68%(2035)로 늘며, 빈집은 4개 동에 44%가 몰려 있고 79%가 다세대다.

**SOS 긴급도 (점수·가중치 없음)**
- 색 = **확인된 위험**(담당자가 확정한 빈집법 제11조 위해 단계, 시 정비방식)과 **점검 기한** 중 더 나쁜 쪽
- 진한 빨강(1단계 위해) / 빨강(2단계 또는 시 안전조치·철거 대상) / 주황(3단계 또는 기한 지남) / 초록(이상 없음·조치 완료)
- 점검 주기 6개월 또는 12개월. 피해 범위 3조건(100m 안 생활시설, 주변 빈집, 주택 밀집)은 주기와 같은 색 안 순서에만 쓴다
- **보라 = 시민 제보 구역**(250m, 30일 안 현장조사). 제보와 AI는 색을 바꾸지 않는다. 확정은 담당자

**흐름:** 시민 제보 → 구역 안 빈집에 연결(D-day) → 현장 사진 AI 판독(5개 항목·일지 초안) → 담당자가 위해 단계 확정 → 조치 완료 → 6개월 뒤 재점검. 모두 빈집별 타임라인에 쌓인다.

**데이터:** 공람안 빈집 목록 158호(점검 장소 130곳으로 묶음) + 국토교통부 GIS건물통합정보(2026-10, 건물 72,171동). 위치는 근사(오차 중앙값 39m), 마지막 점검일은 2026-01-01로 가정.

**기술:** Next.js · TypeScript · React Leaflet · Gemini API · Upstash Redis(배포본 상태 저장) · Vercel

## 폴더

```
VOID/
├─ README.md            ← 지금 이 파일
├─ PRODUCT.md           ← 제품 정의
├─ docs/                ← 최종 결과물 (위 표)
│  └─ 근거/             ← 숫자 출처 (00 색인 + 01~04 원자료)
├─ data/                ← 공람안 PDF·빈집 목록 CSV (위치 데이터는 비공개)
├─ scripts/             ← 데이터 재현 스크립트
├─ app/                 ← 앱(별도 저장소, VOID git 제외)
└─ 이전문서/            ← 작업 과정 보관(최종본 아님)
```

| 경로 | 내용 |
|---|---|
| `scripts/build_houses.py` | 공람안 목록 + GIS로 `data/houses.json`(130곳, 주기·피해 범위) 생성 |
| `scripts/density_stats.py` | 근거 수치(다세대 79%, 군집 R=0.66, 노후 37→68% 등) 재현 |
| `scripts/extract_ansan.py` | 경기도 건물 원본에서 안산 건물만 추출 |
| `이전문서/2026-11-08_발표준비/` | PPT 구성안·장별 비교·이미지 프롬프트, 7분 기획안, 제안서 수정안, 와이어프레임, 비즈니스모델 조사, 디자인 리뷰 |
| `이전문서/reports/`, `research_notes/` | 방향을 정하기까지의 조사·설계 보고서 01~29. 옛 방향(점수, 야간 순찰, 빈집 예측 등)이 섞여 있다 |

## 다시 실행하기

앱:

```bash
git clone https://github.com/yejin1228/wnpwnpdldi.git app
cd app
npm install
npm run dev
```

- http://localhost:3000/admin 에서 빨강 24 · 주황 65 · 초록 41이 보이면 정상
- AI 판독은 `app/.env.local`의 `GEMINI_API_KEY`(없으면 저장된 응답)
- 배포본 시연 초기화: `POST https://ansan-zip.vercel.app/api/reset`

데이터:

```bash
python -I -X utf8 scripts/build_houses.py
```

- 필요 파일 `data/안산 건물 전체 (GIS건물통합정보 202610).csv`는 대용량이라 git에 없다(국토교통부 GIS건물통합정보에서 받아 `extract_ansan.py`로 추출)
