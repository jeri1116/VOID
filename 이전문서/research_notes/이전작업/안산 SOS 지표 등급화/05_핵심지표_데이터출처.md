## Q1. 건물 연식: 사용승인일 + 주용도·구조·세대수, 건물 폴리곤

### Takeaway
속성은 건축HUB 건축물대장 API 표제부(15134735, 월간 갱신, 2026-07-10 수정)로 받는다. 지도 표시에 필요한 건물 폴리곤은 「국토교통부_일별GIS건물통합정보」 SHP(15052097, 일간 갱신)가 1순위다. 다만 SHP에 사용승인일 필드가 실제로 들어 있는지는 이번에 필드 목록으로 확인하지 못했다. 그래서 "SHP 폴리곤 + API 속성을 PNU로 조인"하는 구성이 가장 안전하다.

### Cited Findings
**(A) 국토교통부_건축HUB_건축물대장정보 서비스 (data.go.kr 15134735) [확인]**

### Inferences
- API는 `sigunguCd`+`bjdongCd`가 필수라서, 안산 전체를 받으려면 법정동 목록(상록구·단원구 법정동 전부)을 돌면서 페이지를 넘겨야 한다. 안산의 동 수는 수십 개 수준이므로 개발계정 한도 안에서 하루 이틀이면 수집이 가능할 것으로 본다.
- 지도에 표시하려면 폴리곤이 필요하다. 건축물대장 API에는 좌표가 없으므로(사전지식) GIS건물통합정보 SHP나 브이월드 건물 레이어를 써야 한다.
- 주거 필터는 `mainPurpsCdNm`의 단독주택·공동주택(다가구·다세대·연립·아파트)으로 하고, 빈집 성격에 맞춰 아파트는 제외할지 결정해야 한다.

### Gaps
- GIS건물통합정보 SHP에 사용승인일·주용도·세대수 필드가 있는지, 필드명과 좌표계(EPSG:5186이나 5174로 추정)는 미확인
- 건축HUB API의 개발계정 일일 트래픽 한도와 자동승인 여부는 페이지에 표시되지 않음. 활용신청 화면에서 확인해야 함
- hub.go.kr에 건축물대장(비폐쇄) 표제부 전국 파일이 있는지, 크기와 로그인 필수 여부는 미확인

## Q2. 주변 등록 빈집: 158호 지번을 좌표로 바꾸기, 공개 빈집 데이터 존재 여부

### Takeaway
안산시 빈집만 따로 모은 공개 데이터셋은 찾지 못했다. 결국 「빈집정비계획 공람안」의 지번을 쓰는 방법뿐이다. 지번 끝자리가 가려져 있어("1104-1**") 정확한 필지 지오코딩은 불가능하다. 브이월드 지오코더(PARCEL)로 본번(예: 선부동 1104) 수준까지 좌표를 잡고, 연속지적도에서 본번이 같은 필지들의 중심점을 대표 좌표로 쓰는 근사가 현실적이다.

### Cited Findings
- 브이월드 지오코더 API [확인]: `https://api.vworld.kr/req/address?service=address&request=getCoord&key=…&type=PARCEL&address=관양동 1588-8`. 필수 파라미터는 `request`·`key`·`type`(PARCEL/ROAD)·`address`이고, 선택 파라미터는 `crs`(기본 EPSG:4326, EPSG:5179~5188·3857 지원), `format`(json), `refine`, `simple` — [브이월드 지오코더 가이드](https://www.vworld.kr/dev/v4dv_geocoderguide2_s001.do)
- 하루 40,000건까지 가능. 결과는 실시간으로만 써야 하고 별도 저장소나 DB에 저장하면 안 된다는 이용조건이 있음. 오류코드에는 `INCORRECT_KEY`(등록한 도메인과 다를 때), `OVER_REQUEST_LIMIT` 등이 있음 — [같은 페이지](https://www.vworld.kr/dev/v4dv_geocoderguide2_s001.do)
- 연속지적도 레이어 ID는 `LP_PA_CBND_BUBUN`(2D데이터 API, 토지 분류) — [브이월드 2D데이터 API 목록](https://www.vworld.kr/dev/v4dv_2ddataguide2_s001.do)
- 안산시는 2024·2026년 빈집 행정조사와 1·2기 빈집실태조사를 반영해 빈집정비계획 용역을 진행했고, 빈집 추정 304호를 대상으로 행정조사를 함 [검색요약] — [경인일보](https://www.kyeongin.com/article/1766046)
- 공공데이터포털에는 용인시·양산시 빈집 현황이 공개돼 있지만 안산시 데이터셋은 확인되지 않음. 전국 빈집 지도는 '빈집애'(국토부·행안부·한국부동산원)에서 볼 수 있음 [검색요약] — [data.go.kr 15080142](https://www.data.go.kr/data/15080142/fileData.do); [이코노미스트](https://economist.co.kr/article/view/ecn202503110054)

### Inferences
- 158호는 브이월드 지오코더 1일 한도에 비해 아주 적다. 다만 "저장 금지" 조건이 있으므로 해커톤 결과물에는 "본번 단위 근사 위치, 개별 주소 비공개"로 표기하고, 원 좌표 대신 격자·집계 단위(예: 100m 격자 반경 내 빈집 수)로만 쓰는 것이 이용조건과 개인정보 양쪽 모두에 안전하다.
- 가려진 "1**"은 부번 100~199 범위를 뜻한다. 연속지적도 `LP_PA_CBND_BUBUN`에서 해당 본번과 부번 1xx 필지를 attrFilter로 골라 그 중심점을 쓸 수 있다(파라미터 세부는 미확인).
- 도로명주소 안내시스템(juso.go.kr) 검색 API와 좌표제공 API도 쓸 수 있지만 이번에는 확인하지 못했다. 지번 입력이면 브이월드 하나로 충분하다.

### Gaps
- juso.go.kr 좌표제공 API의 신청 절차와 한도는 미확인(검색 예산 부족)
- 빈집애 사이트에서 안산 데이터를 내려받을 수 있는지 미확인
- 경기데이터드림의 안산 빈집 데이터셋 존재 여부는 직접 조회하지 못함

## Q3. 인구 감소: 행정동별 주민등록인구 2020~2025, 행정동 경계, 법정동↔행정동 매핑

### Takeaway
행정안전부 주민등록 인구통계(jumin.mois.go.kr)에서 읍면동 단위 연간 데이터를 CSV/XLSX로 바로 받을 수 있다. 2008년 이후 자료가 있고 최신은 2026년 10월이다. 신청할 필요가 없어 가장 빠른 경로다. 법정동↔행정동 매핑은 행정기관 코드 데이터나 안산시 통계의 행정동별 법정동 표로 만든다.

### Cited Findings
- jumin.mois.go.kr 「행정동별 주민등록 인구 및 세대현황」 [확인]: 시도·시군구·읍면동 단위의 총인구·세대수·세대당인구·남녀 인구. 월간·연간 탭이 있고 2008년부터 제공(이전 자료는 KOSIS). CSV·XLSX로 다운로드하며 '전체 읍면동 현황' 단위로도 받을 수 있음. 최신 기준월 2026년 10월. 매월 말일 기준으로 다음 달 1일 12시 이후 공표. 등록구분(전체/거주자/거주불명자/재외국민) 필터가 있고, '전체'에는 외국인이 빠짐 — [jumin.mois.go.kr](https://jumin.mois.go.kr/statMonth.do)
- 행정안전부 「행정기관(시도/시군구/읍면동)별·연령별 주민등록인구」(1·5·10세 단위)가 공공데이터포털에 있음 [검색요약] — [data.go.kr 15097972](https://www.data.go.kr/dcat/metadata/15097972); 관련 [15099155](https://www.data.go.kr/data/15099155/fileData.do)
- KOSIS 표 ID `DT_1B04005N`은 이번 검색으로 확인하지 못함 — [검색 결과](https://www.data.go.kr/biz/dcat/metadata/15097972.do)
- 안산시 통계에 행정동별 법정동 구성표(예: 본오1동 = 본오동+팔곡이동, 월피동 = 부곡동·월피동·양상동)가 있음. 다만 행정동 수 표기가 "13동"과 "15개"로 엇갈림 [검색요약] — [안산시 통계](https://www.ansan.go.kr/stat/common/cntnts/selectContents.do?cntnts_id=C0001013)
- 경기도 행정기관 코드 데이터셋은 행정동코드·법정동코드·생성일자를 함께 제공해 매핑에 쓸 수 있음 [검색요약] — [data.go.kr linkedData 74526](https://www.data.go.kr/catalog/74526/linkedData.json)
- 행정동과 법정동은 1:N이나 N:1 관계여서 1:1로 매핑되지 않음 [검색요약] — [전북일보](https://www.jjan.kr/articleAmp/20230818580080)

### Inferences
- 2020~2025년 매년 12월 데이터를 '전체 읍면동 현황'으로 6번 받거나 연간 탭에서 받으면 된다. 증감률은 (2025-2020)/2020으로 계산한다.
- 2020~2025년 사이에 안산에서 행정동이 분동·통폐합됐는지 확인해야 한다. 코드가 바뀐 동이 있으면 시계열이 끊긴다.
- 건물은 법정동 PNU를 가지므로, 건물이 속한 행정동은 행정동 경계 폴리곤과 공간조인해서 정하는 것이 정확하다. 법정동 테이블 매핑만 쓰면 하나의 법정동이 여러 행정동에 걸칠 때 오류가 생긴다.

### Gaps
- 행정동 경계 SHP 출처(SGIS 통계지역경계 vs 브이월드 `LT_C_ADEMD_INFO`)는 이번에 확인하지 못함. 브이월드 2D 목록 첫 페이지에는 나오지 않았음

## Q4. 낮은 땅값: 개별공시지가와 PNU 연결

### Takeaway
브이월드 `getIndvdLandPriceAttr`(PNU+stdrYear)는 블로그 예제로만 확인했고 공식 문서는 확인하지 못했다. 필지가 많을 때는 API를 반복 호출하는 것보다 일괄 파일이 효율적이지만, 안산용 일괄 파일 경로도 이번에는 확인하지 못했다. 해커톤 전에 브이월드 '데이터 다운로드'와 국가공간정보포털에서 「개별공시지가정보」 경기도/안산 파일이 있는지 직접 확인해야 한다.

**PNU·좌표 연결 파이프라인 (5줄)**
1. 기준 레이어: GIS건물통합정보 SHP(또는 연속지적도)를 EPSG:5186으로 통일하고, 각 건물 폴리곤에 PNU 19자리를 부여한다.
2. 건축물대장 표제부: `sigunguCd+bjdongCd+(platGbCd+1)+bun+ji`로 PNU를 만들어 조인하고, 사용승인일·주용도·세대수를 붙인 뒤 주거용만 남긴다.
3. 공시지가: PNU로 직접 조인한다. 인구: 건물 중심점을 행정동 경계 폴리곤과 공간조인해 행정동코드를 얻고, jumin 2020→2025 증감률을 붙인다.
4. 빈집 158호: 지오코더 PARCEL로 법정동+본번의 좌표를 얻고, 건물별로 반경 N m 안의 빈집 수를 계산한다(좌표는 저장하지 않고 집계 결과만 남김).
5. 정비구역: SHP 폴리곤과 건물 중심점을 point-in-polygon으로 판정하고, 구역명으로 단계 테이블을 붙인다. 이후 5개 지표를 행정동 내 백분위로 정규화해 SOS 지수를 계산한다.

### Inferences
- 신청이 필요 없는 jumin 인구와 파일데이터 SHP로 먼저 프로토타입을 만들고, API는 보강용으로 쓰는 순서가 해커톤 일정 리스크를 가장 줄인다.
- 브이월드 지오코더의 "결과 저장 금지" 조건 때문에, 빈집 좌표를 결과물에 고정 데이터로 넣는 것은 피해야 한다.

### Gaps
- 좌표계 EPSG:5186은 권장안일 뿐 각 SHP의 실제 .prj는 미확인
- 이번 조사에서는 건축HUB·2D API의 트래픽 한도와 승인 소요기간을 직접 확인하지 못함
