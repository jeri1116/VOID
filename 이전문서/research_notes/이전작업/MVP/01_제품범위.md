# MVP 제품 범위 초안 (방향 확인용)

기준일 2026-11-07. 팀원이 **방향만** 확인하는 문서다. 세부 설계(점수 공식, 화면 상세, 기술 구성)는 다음 문서에서 다룬다.

**한 줄:** 시가 빈집을 판정·관리하는 데 필요한 현장 정보를 더 빨리, 더 많이, 기록으로 남게 모으는 도구. 빈집을 예측·판정하지 않고, **현장조사 순서**만 정해 준다.

---

## 1. 문제·목표

| 구분 | 내용 |
|---|---|
| 문제 | 안산시 빈집정비계획(2026~2030) 대상 158호 중 91%(상시관리 123 + 안전조치 21)는 철거가 아니라 **점검하고 지켜보는 대상**이다. 계획은 6개월~1년 주기 점검, 사진·일지 DB, 협업 순찰을 요구하지만 **이를 할 도구가 없다.** |
| 압박 | 빈집 신고가 들어오면 시는 **30일 안에 현장조사를 해야 한다**(빈집법 제11조의3, 시행령 제10조의3). 신고가 늘수록 "어디부터 갈지"가 필요하다. |
| 목표 | 시민 제보와 현장점검을 **빈집 단위의 기록 하나**로 묶고, 현장조사 우선순위를 지도로 보여 줘 시 담당자가 먼저 갈 곳을 고르고 결과를 남기게 한다. |

## 2. MVP 범위

| 구분 | 기능 | 해커톤에서 동작하는 기준 |
|---|---|---|
| **P0** | 시민 제보 | 카테고리·제목·글·사진(선택)·위치 입력 후 저장. 화재·붕괴·범죄 진행 중이면 119·112로 바로 안내 |
| **P0** | 우선순위 계산 (규칙) | P(빈집일 가능성 = 안산판 SOS 지수) × H(위해, 제11조 1~4호) × E(노출, 생활시설 인접) + 30일 기한 + 불확실성 가점. AI가 아니라 규칙으로 계산 |
| **P0** | 담당자 지도·목록 | 빨강 > 주황 > 초록 그라데이션, 회색 = 미점검/정보 없음. 점수 순 목록과 점수 분해(왜 이 순위인지) 표시 |
| **P0** | 현장점검 기록 | 사진 → 체크리스트 → 판정(조치 필요 / 관찰 / 이상 없음) 저장 후 색과 이력이 바로 바뀜 |
| **P0** | AI 사진 판독 | 제보·점검 사진에서 보이는 상태(문 개방, 파손, 쓰레기, 우편물 누적, 인화물질 등)를 분류해 체크리스트를 채움. 빈집 여부는 판단하지 않음 |
| **P0** | AI 같은 빈집 제보 묶기 | 새 제보가 기존 빈집 기록과 같은 곳인지 판단해 하나의 이력에 붙임 |
| **P0** | 시민 화면 격자 집계 | 시민 지도에는 격자 단위 색만 보이고 개별 주소는 비공개(제15조⑥) |
| **P0** | 조치 연결 (최소) | 담당 부서 지정과 상태(요청 / 진행 / 완료) 입력 |
| P1 | AI 개인정보 가림 | 사진 속 얼굴·번호판 자동 가림. 안 되면 사진을 담당자 화면에만 보여 주는 것으로 대체 |
| P1 | AI 요약문 | 빈집별 이력 한 문단 요약, 부서 요청문 초안 |
| P1 | 순찰대 조회 화면 | 지도 읽기 전용 |
| P1 | 검증 화면 | AI 사진 판독 vs 팀 판정 일치율 |
| P1 | 점검 유효기간 | 초록에 마지막 점검일 표시, 기한이 지나면 회색으로 복귀 |
| P1 | 가중치 조정 | 시 담당자가 P·H·E 비중을 바꾸면 순위가 바로 바뀜 |
| 제외 | 순찰대 점검·피드백 입력 | 향후계획. 지금은 조회만 |
| 제외 | 빈집 예측·판정 모델 | 서비스 정의상 하지 않음. 판정은 시가 함 |
| 제외 | 외부 데이터 연동 | 전기·수도 사용량, 전국 AI 빈집 위험 예측 지도, 안전신문고. 향후 "교체 가능한 입력"으로 설계만 |
| 제외 | 기관 협업 | 경찰·소방·동 행정복지센터 협업 순찰 연계 |
| 제외 | 조치 전후 사진 비교 AI | 향후계획 |
| 제외 | 실제 로그인·권한 체계 | 데모는 역할 전환 버튼으로 대신 |

## 3. 화면 목록

| # | 화면 | 사용자 | 와이어 수준 설명 | 핵심 동작 |
|---|---|---|---|---|
| S1 | 제보하기 (모바일) | 시민 | 상단 119·112 배너 → 카테고리 버튼 → 제목·글 → 사진(선택) → 지도 핀 | 제출하면 접수번호와 "확인 요청 접수" 안내 |
| S2 | 동네 지도 (모바일) | 시민 | 격자 색 지도 + 내 제보 상태 카드 | 개별 빈집은 안 보임. 내 제보가 접수 / 확인 중 / 조치 중인지 확인 |
| S3 | 대시보드 (PC) | 시 담당자 | 왼쪽 지도(빈집 단위 색 점), 오른쪽 우선순위 목록(D-n 기한 배지) | 목록이나 점을 누르면 S4로. 점수 분해(P·H·E·기한·불확실성) 확인 |
| S4 | 빈집 기록 (PC) | 시 담당자 | 상단 현재 색과 점수, 아래 제보·점검·조치 타임라인 | 묶인 제보 확인, 담당 부서·조치 상태 입력, (P1) AI 요약 |
| S5 | 현장점검 (모바일) | 시 담당자 | 사진 촬영 → AI가 채운 체크리스트 → 판정 3택 → 저장 | 담당자는 틀린 항목만 고침. 저장하면 S3·S4 색과 이력 갱신 |
| S6 | 순찰 지도 (모바일) | 순찰대 | S3 지도의 읽기 전용판 | 우선순위 높은 곳 확인만. 표시 단위는 열린 질문 1 |

## 4. 5분 데모 시나리오

| 단계 | 시간 | 화면 | 보여 줄 것 |
|---|---|---|---|
| 1 | 0:00~0:40 | 슬라이드 | 158호 중 91%는 지켜보는 대상, 점검·기록을 요구하지만 도구가 없음, 신고 30일 기한 |
| 2 | 0:40~1:20 | S3 | 시범 구역 지도. 회색이 많다는 점, 우선순위 1위를 눌러 "왜 1위인지" 점수 분해 |
| 3 | 1:20~1:50 | S1 | 시민이 "문이 열려 있고 쓰레기가 쌓였어요" + 사진 + 위치로 제보 |
| 4 | 1:50~2:20 | S3·S2 | AI가 기존 빈집 기록에 묶음 → 담당자 목록에 D-30 배지와 함께 상단 이동. 시민 지도에는 격자 색만 바뀜(주소 비공개) |
| 5 | 2:20~3:10 | S5 | **라이브:** 심사위원이 인쇄한 현장 사진을 폰으로 찍음 → AI가 체크리스트를 채움 → 담당자가 "조치 필요" 판정 |
| 6 | 3:10~3:40 | S3·S4 | 지도 색이 바뀌고, 한 빈집 기록에 제보와 점검이 시간순으로 쌓인 모습 |
| 7 | 3:40~4:10 | S4·S6 | 담당 부서 지정, 상태 "요청". 순찰대 화면에도 같은 변화가 보임 |
| 8 | 4:10~5:00 | 검증·슬라이드 | AI 판독 vs 팀 판정 일치율, 향후계획(순찰대 점검·데이터 연동) |

가장 강한 장면은 5~6단계다. **사진 한 장이 지도의 순위와 빈집 기록을 바꾸는 장면**은 시간이 모자라도 남긴다. 라이브가 실패하면 캐시 결과로 넘어가는 버튼을 숨겨 둔다.

## 5. 성공 기준

| 심사 항목 (배점) | 이걸 보여 주면 성공 |
|---|---|
| 문제 정의와 근거 (25) | 계획 원문 숫자(158호, 91%, 6개월~1년 점검)와 법정 30일 기한으로 "해야 할 일은 정해졌는데 도구가 없다"를 1분 안에 전달 |
| 해결안 적합성·차별성 (25) | 같은 빈집의 제보·점검·조치가 **하나의 기록**으로 이어지고, 신고 없는 회색 빈집도 순위에 오름. 빈집애·울산 AI(예측)와 안전신문고(건별 처리)와 다른 점을 한 장으로 설명 |
| 실현 가능성 (25) | 제보 → AI 판독 → 색 갱신 → 조치 연결이 **실제로 끊기지 않고 동작**. 화면마다 실데이터 / 팀 수집 / 가상 배지, AI 판독 일치율 수치 |
| 전달력·질의응답 (15) | "왜 예측 안 하나", "개인정보는", "허위 제보는", "안전신문고와 뭐가 다른가"에 각각 한 문장 답 준비 |

## 6. 팀이 결정해야 할 열린 질문

| # | 질문 | 왜 지금 정해야 하나 |
|---|---|---|
| 1 | 순찰대 화면에 개별 빈집 위치를 보여 줄까, 격자만 보여 줄까? | 제15조⑥은 개별 공개를 막고, ⑤의 제공 대상은 행정기관·경찰이다. 자율방범대가 여기에 드는지 확인 필요 |
| 2 | 시범 구역은 어느 동 1~2곳으로 할까? | 158호 목록은 지번 일부가 가려져 있다. 위치를 건물 단위로 붙일지, 근처로 흐려서 붙일지 정해야 지도를 만든다 |
| 3 | 미점검 빈집은 H(위해)가 없는데 곱셈에서 어떻게 처리할까? | H 기본값과 불확실성 가점 크기에 따라 회색 빈집이 순위에 오르는지가 갈린다. 차별점("신고 없는 곳도 관리")과 직결 |
| 4 | P(SOS 지수)는 격자 값을 그대로 쓸까, 건물 특성으로 보정할까? | 해커톤 일정상 격자 값 + 불확실성 가점이 현실적. 보정하면 일이 늘어난다 |
| 5 | 데모 사진은 언제 어디서 몇 장 찍고, 정답 판정은 누가 할까? | 라이브 판독과 일치율 수치(실현 가능성 25점)의 재료다. 촬영 시 얼굴·번호판·주소 노출 기준도 함께 정한다 |

참고: 현행 빈집법 빈집 조항은 2027-09-09부터 새 특별법으로 이관 예정이다. 발표에서는 "현행 빈집법 제○조"로 표기한다.
