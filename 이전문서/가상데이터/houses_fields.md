# 안산 SOS 더미 데이터 필드 설명서

> **전체 200건은 시연용 가상 주택입니다. 실제 건축물 주소, 빈집 위치, 등록 상태, 인구 통계, 공시지가 자료가 아닙니다.**
> 구·동 이름과 법정동/행정동의 관계만 공개 행정구역 정보를 참고했습니다. 개별 주택과 모든 수치·좌표는 합성했습니다.

## 1. 파일과 구성

- 데이터: `houses.json` — UTF-8(BOM 없음), 표준 JSON, 최상위 배열. `JSON.parse()` 결과를 바로 주택 목록으로 사용합니다.
- 레코드 수: **200개**. 25개 행정동에 각각 8개씩 배정했습니다. 표본 배분은 실제 주택 분포와 무관합니다.
- 가상 기존 등록 빈집: **60개** (`is_registered_vacant === true`).
- 가상 신규 분석 후보: **140개** (`is_registered_vacant === false`). 미등록 분석 후보라는 뜻이며 빈집 또는 거주 주택으로 확정한 값이 아닙니다.
- 작성일·가상 기준일: **2026-11-07**. 최근 5년의 가상 기간: **2021-11-07 ~ 2026-11-07**.
- 생성 시드: `20261107`. Python 3.11 표준 라이브러리의 난수로 생성했습니다.
- 모든 필드는 필수이며 `null`, 빈 문자열, `NaN`, 무한대가 없습니다. 숫자에 단위·쉼표·퍼센트 기호를 넣지 않았습니다.
- **Jenks 등급, 분류 경계값, 지표 점수, SOS 지수는 데이터에 포함하지 않았습니다.**

## 2. 데이터 필드

| 필드 | JSON 타입 | 단위·예시 | 설명 |
| --- | --- | --- | --- |
| `house_id` | string | `ANSAN-SOS-DEMO-0001` | 중복 없는 가상 주택 ID. 실제 건축물 관리번호가 아닙니다. |
| `is_synthetic` | boolean | `true` | 전 레코드의 가상 데이터 표시. 항상 `true`입니다. |
| `address` | string | `[가상·시연용] ... SOS가상주택로 D01-001 (실재하지 않는 주소)` | 실제 도로명·지번을 사용하지 않은 가상 주소 문자열. 실제 주소로 지오코딩하지 않습니다. |
| `district` | string | `상록구`, `단원구` | 시연용 구 라벨. |
| `legal_dong` | string | `본오동` | 법정동 라벨. 행정동과 구분합니다. |
| `administrative_dong` | string | `본오1동` | 인구 증감률을 연결하는 행정동 키. 동일 행정동의 8건에는 같은 증감률을 넣었습니다. |
| `latitude` | number | 소수점 이하 6자리, 도 | 지도 표시용 가상 위도. WGS84(EPSG:4326). |
| `longitude` | number | 소수점 이하 6자리, 도 | 지도 표시용 가상 경도. WGS84(EPSG:4326). |
| `coordinate_source` | string | `synthetic_demo_not_geocoded` | 임의 생성 좌표이며 주소 지오코딩·건축물 위치 조회 결과가 아님을 표시합니다. |
| `building_age_years` | integer | 년, 1~75 | 가상 기준일의 건물 경과 연수. 정수입니다. |
| `nearby_registered_vacant_count_500m` | integer | 호, 0~48 | 반경 500m 안의 등록 빈집 수를 흉내 낸 **시연용 합성값**. 의미상 해당 주택 자체를 제외한 주변 주택 수로 취급합니다. |
| `nearby_registered_vacant_count_source` | string | `synthetic_demo_not_spatially_calculated` | 위 주변 빈집 수가 좌표·반경 검색으로 계산되지 않았음을 명시합니다. |
| `population_change_rate_5y_pct` | number | %, -24.8~18.6 | 최근 5년 행정동 인구 증감률의 합성값. `-10.2`는 10.2% 감소, `4.4`는 4.4% 증가를 뜻하며 비율 `0.044`로 저장하지 않습니다. |
| `official_land_price_krw_per_m2` | integer | 원/㎡, 120000~8500000 | 개별공시지가를 흉내 낸 모의값. 실제 공시·조회된 금액이 아닙니다. 정수 원 단위입니다. |
| `is_registered_vacant` | boolean | `true` / `false` | 시나리오상의 기존 등록 빈집 / 신규 미등록 분석 후보 구분. 문자열이 아닌 JSON boolean입니다. |

## 3. 가상 주소·좌표·주변 빈집 수의 해석

주소마다 `[가상·시연용]`과 `(실재하지 않는 주소)`를 붙이고, 가상 도로명과 영숫자 식별자를 사용했습니다. 실제 주택의 주소·지번·건축물 ID를 수집하거나 복제하지 않았습니다.

좌표는 위도 37.29~37.39, 경도 126.77~126.94의 지도 시연 범위에서 임의로 생성했습니다. **동 라벨과 좌표는 독립적으로 부여했으므로, 실제 행정동 경계·안산시 경계·육지·건축물 내부 여부를 보장하지 않습니다.** 대부동을 포함해 동별 실제 위치를 재현하지 않습니다. 좌표가 우연히 실제 지점과 겹치더라도 그곳에 주택이나 빈집이 있다는 뜻이 아닙니다. 지도와 팝업에는 ‘가상 데이터 / 실제 빈집 위치 아님’을 표시합니다. GeoJSON 좌표로 변환할 때 순서는 `[longitude, latitude]`입니다.

주변 빈집 수는 독립적으로 부여한 합성 정수입니다. 이 파일의 `true` 레코드 60개를 반경 검색한 결과와 일치할 필요가 없습니다. 실제 반경 500m 집계로 해석하거나 좌표로 역검증하는 용도가 아닙니다. 지도 기반 집계 기능을 시연하려면 프로그램에서 별도로 재계산하고 계산 방식 표시도 함께 바꿉니다.

인구 증감률의 개념은 `(가상 기준일 인구 - 5년 전 가상 인구) / 5년 전 가상 인구 × 100`입니다. 이 파일에는 인구 원자료 없이 증감률만 합성했습니다. 등록 여부도 시연을 위한 임의 배정이며 통계·모델 성능 평가용 정답 라벨이 아닙니다.

## 4. 지표 분포와 고유값 검증

연식·주변 빈집 수는 넓은 값 범위에 작은 값이 상대적으로 자주 나오는 표본을 추가했습니다. 공시지가는 오른쪽 꼬리가 긴 분포를 사용했으며, 인구 증감률은 감소·보합·증가를 포함합니다. 값의 분포는 시연을 위한 설계이며 실제 안산시의 분포를 추정한 것이 아닙니다. 등급을 부여하기 위한 사전 구간이나 등급 라벨은 사용하지 않았습니다.

아래 수치는 저장된 `houses.json`을 다시 읽어 검증한 값입니다. 중앙값·최솟값·최댓값은 전체 200건 기준입니다.

## 6. 프로그램 연결

```javascript
const houses = JSON.parse(jsonText);
const registeredHouses = houses.filter(h => h.is_registered_vacant);
const candidates = houses.filter(h => !h.is_registered_vacant);

const indicatorKeys = [
  'building_age_years',
  'nearby_registered_vacant_count_500m',
  'population_change_rate_5y_pct',
  'official_land_price_krw_per_m2',
];

// 전체 200건을 입력으로 지표별 분포를 구성합니다.
const valuesByIndicator = Object.fromEntries(
  indicatorKeys.map(key => [key, houses.map(h => h[key])])
);
// 이후 프로그램에서 각 지표의 Jenks 5등급을 계산하고
// 위험 방향을 맞춘 4개 등급의 산술평균으로 최종 SOS 지수를 계산합니다.
```

등급 경계는 필터링 전 **전체 200건**에서 지표별로 계산합니다. 기존 등록 여부는 점수 지표에 포함하지 않으며, 신규 분석 결과를 표시할 때 `candidates`를 사용합니다. 인구 증감률은 같은 행정동의 주택마다 반복되는 값을 그대로 전체 분포에 포함합니다. 이번 표본은 행정동당 8건으로 가중치가 동일합니다.

위험도 방향은 프로그램에서 통일합니다. 연식·주변 빈집 수는 큰 값에 높은 위험등급을 부여하고, 인구 감소를 위험 요인으로 사용할 때는 인구 증감률의 낮은 값에 높은 위험등급을 부여합니다. 저지가를 위험 요인으로 채택한다면 공시지가도 역방향으로 처리합니다. **공시지가의 위험 방향은 분석 정책에서 확정할 사항입니다.** 이 파일에는 그 판단이나 산출 등급을 미리 저장하지 않았습니다.

## 8. 행정구역 명칭 참고 자료

[안산시 통계 — 행정동 위치도·행정구역 표](https://www.ansan.go.kr/stat/common/cntnts/selectContents.do?cntnts_id=C0001013) (공개 표의 기준일: 2024-12-31, 열람일: 2026-11-07).

이 자료에서는 구·동 명칭과 법정동/행정동의 관계만 참고했습니다. 행정구역 전체 표나 지도를 복제하지 않았으며, 실제 주소·등록 빈집 자료·인구 증감률·개별공시지가·좌표는 가져오지 않았습니다. 2026년 최신 행정경계를 검증한 자료는 아닙니다.
