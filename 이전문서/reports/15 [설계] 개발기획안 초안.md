# 개발기획안 초안: 안산 빈집 안전 SOS (가칭)

## 한 줄 정의

**시가 빈집을 판정하고 관리하는 데 필요한 현장 정보를, 더 빨리·더 많이·기록으로 남게 모으는 도구.**

빈집을 예측하거나 판정하지 않는다. 판정은 시가 하고, 우리는 시민과 순찰대의 현장 정보를 모아 시가 쓸 수 있는 점검 기록으로 만든다.

## 문제

- 안산시 빈집정비계획(2026~2030)은 "관리되지 않는 빈집은 범죄·무단점유의 장소로 악용될 수 있고 (…) 인접 주거지의 주거환경을 저해하고 지역 쇠퇴를 가속"한다고 진단했다.
- 계획 대상 158호 중 **91%(상시관리 123호 + 안전조치 21호)는 철거가 아니라 "점검하고 지켜보는" 대상**이다. 계획은 6개월~1년마다 현장 점검을 하고, 사진·일지를 DB에 쌓고, 경찰·소방·동 행정복지센터와 협업 순찰을 하라고 정했다.
- **하지만 누가, 어떤 도구로, 어떻게 기록할지는 정해져 있지 않다.** 실태조사는 5년 주기이고, 데이터로 고른 빈집 후보의 절반은 실제 빈집이 아니다(판정률 51%).

## 사용자와 하는 일

| 사용자 | 하는 일 |
|---|---|
| **시민** | 문제 카테고리 선택 → 제목·간단한 글 → 사진(선택) → 위치. 처리 상태 알림을 받는다 |
| **순찰대** (자율방범대·동 살핌이) | 우선순위 높은 곳을 방문해 외관 사진 촬영 → 확인 결과(조치 필요 / 관찰 / 이상 없음) 피드백. 개선되면 전후 사진으로 업데이트 |
| **시 담당자** | 지도에서 빈집별 상태·이력 확인 → 담당 부서·소유자 조치 연결 → 조치 상태 입력 |

## 핵심 기능

1. **우선순위 지도:** 빈집(건물 단위)을 **빨강(긴급 점검·조치) > 주황(일반 점검·관리) > 초록(최근 점검상 이상 없음) / 회색(미점검)**으로 표시. 초록에는 마지막 점검일을 함께 표시하고, 기한이 지나면 회색으로 돌아간다.
2. **시민 제보:** 카테고리는 출입·침입 흔적, 시설 파손·붕괴 징후, 화재 위험, 쓰레기·방치, 기타. 긴급 상황(화재·붕괴·범죄 진행 중)은 119·112로 바로 안내한다. 제보는 "확인 요청"으로만 받고, 순찰대가 확인한 뒤에 확정된다.
3. **순찰대 점검:** 점검 경로 안내 → 사진 촬영 → AI가 체크리스트 자동 작성 → 대원은 애매한 항목만 고침 → 제출.
4. **장소 단위 이력:** 같은 빈집에 들어온 제보, 점검, 조치를 하나의 기록으로 묶는다. 다세대는 같은 건물의 여러 호를 함께 관리한다.

## 점검 우선순위 요소

- **빈집 자체:** 등급, 정비방식(안전조치·철거 대기), 구조, 공실 기간
- **점검 기한:** 6개월~1년 주기를 넘겼는지
- **현장 신호:** 출입 흔적, 창호·출입문 파손, 쓰레기, 우편물 누적, 인화물질, 균열, 직전 대비 악화
- **주변 맥락:** 학교·어린이집·경로당 등 생활시설 인접, 같은 건물 내 빈집 증가, 주변 빈집 밀집, CCTV·보안등 공백
- **외부 신호:** 시민 제보, 민원

대부분 **안산시 빈집정비계획이 협업 순찰 대상 조건으로 직접 적은 항목**이다. 점수 계산과 색 결정은 규칙으로 하고, 시가 가중치를 조정할 수 있다.

## AI가 하는 일

| AI | 하는 일 |
|---|---|
| 사진 판독 | 순찰대·시민 사진에서 보이는 상태(문 개방, 파손, 쓰레기, 우편물, 인화물질 등)를 정해진 항목으로 분류. 빈집 여부는 판단하지 않는다 |
| 개인정보 가림 | 사진 속 얼굴·번호판 자동 가림 |
| 제보 연결 | 새 제보가 이미 있는 어느 빈집 기록과 같은 곳인지 판단해 묶는다 |
| 전후 비교 | 조치 전후 사진을 비교해 개선 여부 판정 |
| 요약·전달문 | 빈집별 이력 요약, 담당 부서 요청문 초안 |

## 데이터

- **쓸 수 있음:** 안산시 빈집정비계획 공람안 158호 목록(지번 일부 가림), 건축물대장, CCTV·보안등 표준데이터, 생활시설 위치, 정비구역 경계, 팀 현장 사진, 시민 제보
- **못 씀(향후계획):** 세대별 전기·수도 사용량, 소유자 정보, 행정조사 목록, 전국 AI 빈집 위험 예측 지도

## 차별점

| 비교 대상 | 그쪽 | 우리 |
|---|---|---|
| 빈집애·울산 AI 빈집관리 | 데이터로 빈집을 **예측·현황 관리** | 예측 이후의 **현장 확인·지속 관리** |
| 안전신문고 | 위험 하나를 신고하면 처리하고 끝 | 같은 빈집의 제보·점검·조치를 **하나의 기록으로 반복 관리**, 신고 없는 곳(회색)도 관리 |
| 종로구 빈집 안전살핌이 | 주민 40여 명이 직접 점검, 디지털 도구 언급 없음 | 같은 사람 구조에 **우선순위·기록·추적 도구**를 붙임 |
| 다른 팀(부동산 활용, 주거환경 통합) | 빈집 활용·거래, 시설 통합 | 빈집 **안전·노후 관리** |

## MVP 범위 (해커톤)

- 시범 구역 1~2곳(공람안 대상 빈집이 몰린 동)
- 화면 3개: 시민 제보, 순찰대 점검, 시 관리 지도
- 데모: 시민 제보 → 지도에 확인 요청 표시 → 순찰대 사진 점검(AI 판독) → 지도 색과 이력 갱신 → 시 담당자 조치 목록
- 검증: 팀이 찍은 사진으로 AI 판독과 사람 판정의 일치율 공개

## 향후계획

1. **데이터 협약:** 전기·수도 사용량, 전국 AI 빈집 위험 예측 지도를 입력으로 연동
2. **예측 검증:** 우리 현장 기록("빈집 맞음/아님", 상태 변화)을 예측 모델의 정답 데이터로 제공해 판정률 개선
3. **기관 연계:** 경찰 탄력순찰 요청, 소방·동 행정복지센터 협업 순찰로 확대

## 확인할 것

- 안산시 빈집 담당자 인터뷰: 지금 상시관리 점검을 누가 어떻게 하는지
- 자율방범대 인터뷰: 빈집을 따로 보는지, 본 것을 어디에 기록하는지
