# 직접 확인할 링크와 검색어

조사 에이전트가 막혀서 열지 못한 곳을 정리했습니다. 위에서부터 중요한 순서입니다. 체크박스에 표시하며 진행하세요.

---

## 1. 안산시 조례 본문 (법령정보센터)

자동 조회에서는 본문이 로딩되지 않았습니다. 브라우저로 열면 보입니다.

- 사이트: https://www.law.go.kr → 상단 탭 **자치법규** → 검색창에 조례명 입력
- 대안: https://www.elis.go.kr (자치법규정보시스템) → 지역 **경기도 > 안산시** 선택 후 검색

| 확인 | 검색할 조례명 | 본문에서 찾을 것 |
|---|---|---|
| [ ] | 안산시 빈집 및 소규모주택 정비에 관한 조례 | 철거·보수비 **보조** 조항, 안전조치 **명령**·이행강제금, 빈집 활용(주차장·쉼터) |
| [ ] | 안산시 가로등 및 보안등 설치ㆍ관리 조례 | 고장 **신고** 방법, **원격관리**·스마트보안등, 사유지 보안등 지원, 수리 기한 |
| [ ] | 안산시 스토킹범죄 예방 및 피해지원에 관한 조례 | 2025 개정분의 **주거이전·이사비·임시숙소·경호** 조항 |
| [ ] | 안산시 범죄피해자 보호 및 지원에 관한 조례 | 주거침입 피해가구 **방범시설 설치** 지원 조항 |
| [ ] | 안산시 전기통신금융사기 피해 예방에 관한 조례 | 보이스피싱 **보험 가입 지원** 조항 |
| [ ] | 안산시 소규모 노후주택 집수리 지원에 관한 조례 | 빈집도 대상인지, 방범창·잠금장치가 지원 항목인지 |
| [ ] | 안산시 자율방범대 지원 조례 / 반려견 순찰대 지원 조례 | 시설 점검 활동을 맡길 수 있는 근거 |
| [ ] | 안산시 범죄예방 도시디자인 조례 (있는지 자체를 확인) | 셉테드 사후관리·점검 조항 |

## 2. 안산시 누리집 (ansan.go.kr)

검색 주소가 404였고 검색창이 자바스크립트로 그려져 자동으로 쓸 수 없었습니다. 브라우저에서 우측 상단 **통합검색**을 쓰세요.

| 확인 | 검색어 | 무엇을 확인하나 |
|---|---|---|
| [ ] | 스마트보안등, 스마트 가로등 | 주거지 원격관리 보안등이 있는지 (산단 말고) |
| [ ] | 보안등 고장신고, 가로등 고장 | 전화 외 신고 경로(앱·QR·관리번호)가 있는지 |
| [ ] | 비상벨 점검, 안심비상벨 | 정기점검과 결과 공개 여부, IP형 교체 완료 여부 |
| [ ] | 안심귀갓길 점검, 모니터링단, 안전점검단 | 시민참여 야간 점검 사업이 있는지 |
| [ ] | 빈집 정비, 빈집 철거 지원 | 보조금 공고, 실적 |
| [ ] | 안심택배함 | 운영 여부 |
| [ ] | 방범창, 방범장비 지원, 여성안심패키지 | 시공형 장비 지원이 있는지, 대상 범위 |
| [ ] | 소상공인 안심벨, 무인점포 | 방범 지원 여부 |

직접 열어 볼 페이지:
- [ ] 상록구 도로조명관리(보안등 고장신고 안내): https://www.ansan.go.kr/sangnokgu/common/cntnts/selectContents.do?cntnts_id=C0000163
- [ ] 단원구 같은 메뉴 (구청 누리집 > 분야별정보 > 도로·조명)
- [ ] 안산시 보도자료 게시판 (시정소식 > 보도자료)에서 위 검색어 반복

## 3. 안산시의회 회의록

호출 예산 부족으로 검색하지 못했습니다.

- 사이트: https://council-record.ansan.go.kr → 회의록 검색
- [ ] 검색어: **CCTV 고장**, **CCTV 노후**, **관제요원**, **비상벨**, **보안등**, **가로등 고장**, **빈집**, **치안**, **안전지수**
- 볼 회의: 행정사무감사(매년 6월경), 예산결산특별위원회, 본회의 5분 자유발언

검색으로 안 나오는 수치는 청구가 가장 확실합니다. 결정까지 보통 10일 정도 걸리니 먼저 넣으세요.

1. "2023~2026년 안산시 보안등·가로등 고장 신고 접수 건수, 접수 경로(전화·방문·앱 등)별 건수, 접수부터 수리 완료까지의 평균 처리일수, 원격감시 기능을 갖춘 보안등 수량"
2. "2024~2026년 안산시 방범 비상벨 설치 대수, 방식(IP형·아날로그형)별 수량, 정기점검 실시 주기와 점검 결과(정상·불량 건수), 불량 조치 내역"
3. "2023~2026년 안산시 방범 CCTV 설치연도별 대수, 200만 화소 미만 대수, 연도별 고장·장애 건수와 평균 복구일수, 관제요원 근무조별 인원"
4. "「안산시 빈집 및 소규모주택 정비에 관한 조례」에 따른 2024~2026년 빈집 철거·보수·안전조치 보조금 집행 건수와 금액, 안전조치 명령·이행강제금 부과·직권철거 건수, 2026년 빈집 행정조사 304호의 행정동별 분포"
