# 핵심 지표 5개 데이터 출처

안산판 SOS 지수 핵심 지표 5개(건물 연식, 주변 등록 빈집, 인구 감소, 낮은 땅값, 정비구역)의 데이터 출처를 정리했다.

> 표기: **[확인]** 페이지 직접 확인, **[검색요약]** 검색 결과로만 확인, **[미확인]** 근거 못 찾음. 기준일 2026-11-07. 원자료 노트: `이전문서/research_notes/이전작업/안산 SOS 지표 등급화/05_핵심지표_데이터출처.md`.

## 1. 지표별 데이터

### ① 건물 연식

| 구분 | 데이터 | 내용 | 상태 |
|---|---|---|---|
| **1순위 (속성)** | 국토교통부 건축HUB 건축물대장정보 서비스 API ([data.go.kr 15134735](https://www.data.go.kr/data/15134735/openapi.do)) | 표제부에서 사용승인일, 주용도, 구조, 세대수. JSON/XML, 무료, 월간 갱신(2026-07-10 수정) | [확인] |
| **1순위 (위치)** | 국토교통부 일별 GIS건물통합정보 SHP (data.go.kr 15052097) | 건물 폴리곤. 일간 갱신(2025-09-08 수정) | [확인] (사용승인일 필드·좌표계는 [미확인]) |
| 대안 | 건축데이터 민간개방(hub.go.kr) 표제부 일괄 파일 | 매월 20일 전월분 공개. 전국 전체 파일만 보임 | [확인] |

- **호출 방법:** 표제부는 `sigunguCd`와 `bjdongCd`가 필수입니다. 안산 전체를 받으려면 법정동 목록을 돌며 호출해야 합니다.
- **쓸 필드(사전지식, 활용가이드로 확인):** `useAprDay`(사용승인일), `mainPurpsCdNm`(주용도), `strctCdNm`(구조), `hhldCnt`(세대수).
- **시군구코드:** 상록구 41271, 단원구 41273 [미확인, 코드표 대조 필요].

### ② 주변 등록 빈집

| 구분 | 데이터 | 내용 | 상태 |
|---|---|---|---|
| **원자료** | 안산시 빈집정비계획(2026~2030) 공람안 부록 | 158호 목록(빈집코드, 법정동, 지번 끝자리 가림, 유형, 등급, 정비방식) | [확인] (팀 보유 PDF) |
| **좌표 변환** | 브이월드 지오코더 API | `type=PARCEL`로 지번 → 좌표, 하루 4만 건 | [확인] |
| 대안 | 연속지적도 필지 경계 (브이월드 `LP_PA_CBND_BUBUN`) | 같은 본번 필지들의 중심점으로 근사 | [검색요약] |

- **지번이 가려져 있습니다.** 정확한 필지는 못 잡고 본번 단위로 근사합니다. 정확한 지번은 정보공개청구로 받아야 합니다.
- **주의:** 지오코더 이용조건상 변환 결과를 별도 DB에 저장하면 안 됩니다 [확인]. 해커톤 시연용으로만 쓰고, 운영 단계에서는 시 내부 좌표를 씁니다.
- 안산시 빈집을 따로 모은 공개 데이터셋은 data.go.kr에 없습니다 [확인]. 경기데이터드림은 [미확인].

## 3. 데이터 연결 순서

1. 건축물대장 표제부(안산 법정동별 호출)에서 주거용 건물만 걸러 PNU를 만든다.
2. GIS건물통합정보 폴리곤과 PNU로 붙여 건물 좌표를 얻는다.
3. PNU로 개별공시지가를, 좌표로 정비구역 SHP와 행정동 경계를 공간조인한다.
4. 행정동에 주민등록 인구 변화율을 붙인다.
5. 공람안 158호를 지오코딩해 건물마다 반경 500m 등록 빈집 수를 계산한다.
