# 21 [지표] 반경 내 빈집 수 계산 방법

팀원 질문: "반경 500m 내 빈집 수는 어떻게 구하고, 데이터는 뭘 쓰나?"

한 줄 답: 공공 건물 SHP에서 안산 건물 좌표를 뽑는다. 공람안 빈집 158호의 가려진 지번을 그 건물 지번에 맞춰 위치를 근사한다. 그다음 주택마다 반경 안 빈집을 센다.

코드: `scripts/extract_ansan.py`(건물 추출), `scripts/analyze.py`(위치 근사·반경 계산). 이 문서는 이미 돌린 결과를 설명만 한다.

## 2. 계산 순서

| 단계 | 하는 일 | 규칙 | 결과 |
|---|---|---|---|
| 1. 안산 건물 걸러내기 | SHP 3개(DBF)를 훑어 시군구코드가 41271·41273인 행만 남김 | 도형이 빈(null) 건물은 버림. 도형 외곽 사각형(xmin~xmax, ymin~ymax)의 가운데를 좌표로 씀 | 72,171동 → `data/안산 건물 전체 (GIS건물통합정보 202610).csv` |
| 2. 주택만 남기기 | 용도명이 `단독주택` 또는 `공동주택`인 건물 | 용도명 빈칸 건물(약 48%)은 주택에서 빠짐 | 23,723동 |
| 3. 가린 지번 매칭 | 빈집 1호마다 같은 법정동 건물 중 지번 패턴이 맞는 건물을 후보로 찾음 | 아래 표 참고 | 158호 모두 위치 잡힘 → `data/안산 빈집 158호 위치 근사.csv` |
| 4. 반경 안 개수 세기 | 주택마다 반경 150 / 300 / 500m 안 빈집 수를 셈 | 직선거리(평면 좌표, 미터). 격자 색인으로 빠르게 | 0개 비율: 500m 31.1%, 300m 45.8%, 150m 69.4% |
| 5. 최근접 거리 | 주택마다 가장 가까운 빈집까지 거리 | 약 1km 안에 빈집이 없으면 빈칸 | 중앙값 236m → `data/안산 주택 최근접빈집거리.csv` |

### 3단계 세부: 가린 지번 매칭 규칙

| 순서 | 규칙 | 예시 |
|---|---|---|
| 1 | `*` 앞부분을 접두어로 씀. `**`는 실제로는 마지막 한 글자가 가려진 것 | `1104-1**` → 접두어 `1104-1`, 실제 지번은 `1104-1x` |
| 2 | 같은 법정동 안에서만 찾음 | 대부남동 빈집은 대부남동 건물만 비교 |
| 3 | 접두어 + 정확히 한 글자인 지번을 후보로 | `1104-1` + 1글자 → `1104-10`~`1104-19` |
| 4 | 후보가 없으면 접두어 + 두 글자로 한 번 더 찾음 (대체 매칭). 이번 실행에서는 0호 (158호 모두 한 글자 규칙으로 매칭) | `128**` → `128`+2글자 |
| 5 | 후보 중 주택이 있으면 주택만 씀. 없으면 후보 건물 전체 | 주택 후보 우선 |
| 6 | 남은 후보 건물 좌표의 평균을 빈집 위치로 | 후보 3동이면 3동 중심점 평균 |
| 7 | 후보들이 평균점에서 가장 멀리 떨어진 거리를 "근사 오차"로 기록 | `후보최대퍼짐m` 열 |

### 4단계 세부: 격자 색인

| 항목 | 내용 |
|---|---|
| 격자 크기 | 500m × 500m |
| 방법 | 빈집을 좌표로 격자 칸에 미리 넣어 둠. 주택마다 자기 칸과 주변 5×5칸(앞뒤 2칸씩)의 빈집만 거리 계산 |
| 이유 | 23,723동 × 158호 전체 비교를 피함 |
| 탐색 범위 | 최소 약 1km까지 보장. 그래서 반경 500m 계산은 빠짐없음 |
| 개수 표기 | 10개 이상은 `10+`로 묶어 분포를 셈 |

## 3. 한계와 주의

| 항목 | 내용 | 영향 |
|---|---|---|
| 위치 근사 오차 | 가린 지번이라 정확한 건물을 모름. 후보 퍼짐 중앙값 39m, 90% 128m, 최대 564m | 150m 반경은 오차에 민감. 500m는 비교적 안정. 퍼짐이 큰 빈집은 따로 표시해 보는 게 좋음 |
| 용도 빈칸 건물 제외 | 건물의 약 48%가 용도명 빈칸 | 실제 주택이 빠져 주택 수가 과소. 빈집 후보에서도 주택 우선 규칙이 덜 작동할 수 있음 |
| 외곽 사각형 중심점 | 건물 도형의 무게중심이 아니라 외곽 사각형 가운데 | 큰 아파트 단지나 ㄱ자 건물은 수십 m 어긋날 수 있음 |
| 자기 자신 포함 | 빈집 위치가 같은 지번 주택 좌표의 평균이라, 그 주택 자신이 반경 0~수십 m 안 빈집 1개로 잡힘 | 해당 주택은 "주변 빈집 수"가 최소 1로 부풀려짐 |
| 검증 시 정답 누출 | "이 집이 빈집인가"를 맞히는 모델에 이 지표를 넣으면 자기 자신이 섞여 성능이 과대평가됨 | 검증할 때는 같은 지번(또는 같은 빈집코드) 빈집을 빼고 다시 세야 함 |
| 빈집 목록 범위 | 공람안 `계획대상` 158호만. 시 전체 빈집 실태조사 전수가 아님 | 0개 비율(500m 31.1%)은 "정비계획 대상 빈집 기준" 값 |
| 결과 저장 제한 | 브이월드 지오코더(주소→좌표 API)를 쓰지 않음. 공개 SHP 파일의 건물 좌표만 씀 | 지오코더 결과 저장 금지 조건은 해당 없음 |

## 4. 다시 돌리는 방법

`D:\dev\VOID`에서 실행한다. 표준 라이브러리만 쓴다.

```
python -I -X utf8 scripts/extract_ansan.py "data/AL_D010_41_20261009" "data/안산 건물 전체 (GIS건물통합정보 202610).csv"
python -I -X utf8 scripts/analyze.py "data/안산 건물 전체 (GIS건물통합정보 202610).csv" "data/안산 빈집정비계획 공람안 빈집목록.csv" "data/안산 주택 최근접빈집거리.csv" "data/안산 빈집 158호 위치 근사.csv"
```

| 명령 | 인자 순서 |
|---|---|
| extract_ansan.py | SHP 폴더, 출력 건물 CSV |
| analyze.py | 건물 CSV, 빈집목록 CSV, 출력 주택 거리 CSV, 출력 빈집 위치 CSV |

analyze.py는 건물 수, 위치 근사 결과, 반경별 분포, 동별 비율을 화면에 출력한다.
